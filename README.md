# Portfolio

A personal portfolio website built with Next.js and TypeScript. This site showcases profile details, work experience, skills, strengths, certifications, hobbies, and contact information in both English and Japanese.

## Features

- Fully responsive portfolio website
- English / Japanese language switch
- Multiple sections for About, Profile, Work, Skills, Strengths, Certifications, Hobbies, and Contact
- Uses Next.js App Router and CSS modules for styling
- Includes project images and icon artwork

## Pages

- `/` - Home page with introduction and featured content
- `/about` - About section with background and motivation
- `/profile` - Profile details and personal summary
- `/work` - Work experience and project highlights
- `/skill` - Technical skill set
- `/strengths` - Personal strengths and soft skills
- `/certifications` - Certifications and education
- `/hobby` - Hobbies with bilingual descriptions
- `/contact` - Contact form and inquiries

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- CSS Modules

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Build

Create a production build:

```bash
npm run build
```

## Deploy

This project can be deployed to Vercel. Connect your GitHub repository, select the project, and Vercel will configure the build settings automatically for Next.js.
